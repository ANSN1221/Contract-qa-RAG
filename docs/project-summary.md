# 合同条款问答系统 · 项目成果

**一句话**：让合同问答的每条回答都能翻到原文核对——文件名、章节、条款、页码。

## 要解决的问题

合同与招标文件动辄几十页，人工查条款慢；直接问通用大模型，它会编造条款、给不出处。
现成 RAG 框架按字数切 PDF，条款被拦腰切断，召回后既读不完整，也无法回溯页码。

## 技术方案

| 环节 | 做法 | 为什么不用现成方案 |
|---|---|---|
| 解析切分 | PyMuPDF 取文 + 自研切分器，按「第X条」「一、」编号切，保留章节路径与页码 | 按字数切会把条款切断，页码不可回溯（有对照实验） |
| 检索 | BM25（关键词检索）+ 向量双路，RRF（倒数排名融合）加权 | 单一路径对同构表格、术语变体都会漏 |
| 生成 | 严格 JSON 输出，答案与引用 ID 强绑定 | 自由文本无法程序化校验引用 |
| 校验 | verify 节点：规则校验 + 模型核对，不通过回退重生成，最多 2 轮 | 只生成不校验，编造与假引用拦不住 |
| Agent（智能体）路径 | 4 个工具：检索、读原文、读相邻条款、交卷；模型自主决定检索策略 | 固定链路「一次召回定生死」，换说法重搜要靠模型自己判断 |

## 指标（全部为实测值）

| 指标 | 数值 |
|---|---|
| 切分结果 | 10 份 PDF → 766 条条款，页码区域命中 **94.0%** |
| 检索 Recall@5（35 道可答题） | **89%**（混合 1:1） |
| 端到端双正确：答案对且引用对（固定链路） | **89%**（32/36） |
| 端到端双正确（Agent） | **94%**（34/36） |
| 正确拒答（固定链路 / Agent） | **93% / 100%** |
| 单题耗时（固定链路 / Agent） | 4.67s / 7.69s |

评测集为 50 条人工出题并逐条核验的种子题（事实 19 / 跨条款 17 / 不可答 14），
判定脚本可复跑：`uv run python scripts/evaluate_e2e.py [--agent]`。

## 关键决策与负结果

**1. 融合权重定为 1:1，而不是直觉上的「关键词优先 2:1」。**
实测 RRF k=60、召回深度 20 时，权重比超过约 1.31 会把单路命中的答案挤出前 5。
调成 1:1 后混合召回从 85% 升到 89%。

**2. 重排（rerank）保持关闭。**
四轮评测零召回增益：它只能重排候选池内的条款，池外的答案救不回来，每题还多花约 0.5 秒。

**3. 三次尝试修表格类边界题，全部失败并回滚。**

| 方案 | 结果 |
|---|---|
| 字段级切分（把长条款按字段编号切碎） | 混合召回 88% → 82% |
| 父子索引（保留父条款，另加 583 个字段碎片） | 混合召回 82%，重排路径也退化 |
| PDF 表格还原成「字段名：值」文本 | 页码命中 94.0% → 82.5%，目标题仍未解决 |

根因不是参数，而是设计冲突：**条款是引用单元，字段是检索单元**。
要命中就得切碎，切碎就破坏引用可回溯性。这三次实验的结论与数据都写进了
`docs/d5-findings.md`，避免后来者重复踩坑。

**4. Agent 贵 4 倍但值得可选。**
它能换三种说法反复搜、按条款 ID 读原文，修好了固定链路的两道边界题
（疫苗投标保证金、运维服务期）。默认仍走固定链路，`--agent` 按需开启。

**5. 主备供应商自动切换，受控实测通过。**
对话接口支持主备配置，主接口鉴权失败（401）或余额不足（402）时自动切到备用。
实测做法：把主密钥临时置为无效值，备用（硅基流动 DeepSeek-V3）接管，
给出的答案与主接口一致；测完恢复原配置。
只对「接口失败」切换，内容质量问题不换模型——避免把答案不合格掩盖成「换一家再答」。

## 已知边界

- 4 道同构表格 / 表格碎片题不可答（占可答题约 11%），已归档为设计边界
- Agent 单题成本约为固定链路 4 倍，响应慢约 65%
- 单轮问答，无会话记忆；10 份文件、5 份扫描件未做 OCR（光学字符识别）

## 技术栈与仓库

Python 3.11 · LangGraph（状态机）· Chroma（向量库）· PyMuPDF（PDF 解析）·
rank-bm25（关键词检索）· Streamlit（界面）· DeepSeek（对话模型）· bge-m3（向量模型，1024 维）

仓库：`github.com/ANSN1221/Contract-qa-RAG`
启动：`uv run streamlit run src/contract_qa/app.py`
命令行：`uv run contract-qa ask "..." [--agent]`
