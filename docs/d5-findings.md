## 三、四个发现

### 1. 当前默认权重比超过压制阈值（两轮复现）

Q06「货款分几次结清」的实证：

| 环节 | 答案条款 DOC002-C0006 的名次 |
|---|---|
| BM25 单独 | 前 20 条内完全没有 |
| 向量单独 | 第 1 名 |
| 融合 1.0 / 0.5 | **第 21 名** |
| 融合 1.0 / 1.0 或 0.5 / 1.0 | 第 5 名 |

原因可算：RRF 分数为 `weight / (k + rank)`，k=60。向量第 1 名得分 `0.5/61 = 0.0082`，BM25 第 20 名得分 `1.0/80 = 0.0125`。**BM25 的长尾压过了向量的头部。** 阈值：权重比超过 `(60+20)/(60+1) ≈ 1.31` 必然发生，当前 2.0 超标。

### 2. rerank 三轮均无召回增益

- C 组与 D 组三轮全部同分（90/90、80/80、85/85）。
- rerank 只重排候选池内条款，救不回池外条款。
- Q10、Q23 等题有排序提升（第 3 → 第 1），但 Recall@5 不变。

结论：瓶颈在召回与切分，不在排序。保持默认关闭。

### 3. 剩余边界题：四道全灭，两类根因

50 题下四道全灭（占 34 道可答题的 12%）：

| 题 | 答案条款 | 现状 | 类型 |
|---|---|---|---|
| Q24 疫苗投标要交保证金吗 | DOC005-C0009-6、C0012-5 | BM25 第 18 / 第 16 名，向量前 20 没有 | 同构表格 |
| Q20 评标委员会几个人 | DOC003-C0011-4 | 两路前 20 都没有 | 同构表格 |
| Q34 潢川农药一亩用多少 | DOC009-C0037 | 两路前 20 都没有 | 表格碎片 |
| Q43 廉政合同何时生效 | DOC010-C0006 等 3 条 | 两路前 20 都没有 | 标题与正文被切断 |

两类根因：

1. **同构表格条款**（Q20、Q24）：招标文件切分后产生大量 440–500 字的「条款号 名称 编列内容」段落，答案条款与几十个兄弟条款几乎同构，只有中间一行字不同，向量与 BM25 都无法定位。
2. **切分边界**（Q34、Q43）：Q34 的答案在「采购清单」表格碎片里，单元格按列错序，文字与阅读顺序不一致；Q43 的三条生效条款本身不含「廉政合同」字样（标题被切到上一片段），检索词无法命中。

两类都需要字段级结构化抽取或表格重建才能解决，不是检索参数能调的。

### 4. 样本扩到 50 题，结论稳定

三轮数据（10 题、20 题、50 题）方向一致：

- 向量检索稳定强于关键词（85% vs 79%），与 D3 时期「投标保证金」类术语题的结论相反——差异来自题库构成。
- 权重 1:1 稳定优于 2:1（50 题：88% vs 85%）。
- rerank 四轮零召回增益。
- 混合检索优于单路（88% vs 85% / 79%），但差距不大，说明两路互补的收益被 4 道边界题摊薄。

## 四、已否证的方案：字段级切分（2026-11-15 实验）

为了修 Q20/Q24，试过两种字段级切分，均低于基线：

| 方案 | 条款数 | A | B | C | D |
|---|---|---|---|---|---|
| 基线（当前） | 766 | 79% | 85% | **88%** | 88% |
| 替换式：长条款按字段切成碎片，父条款丢弃 | 1026 | 76% | 79% | 82% | 88% |
| 父子索引：保留父条款，另加字段碎片 | 1213 | 79% | 79% | 82% | 85% |

失败原因：

- **碎片互相竞争**：同一前附表切出的几十个碎片语义高度相似，问「评标委员会几个人」时，含答案的碎片未必排第一，反而把原本能命中的整条条款挤出了前 20。
- **短碎片缺上下文**：82 字的碎片丢了所属章节信息，向量表示不稳，B 组从 85% 掉到 79%。
- **父子索引也救不回来**：父条款虽仍入库，但 583 个碎片额外占用 top20 名额，原条款被挤出；D 组反而从 88% 降到 85%。

同时验证了「无编号标题识别」（把「廉政合同」判为章节标题）：能识别「安全生产合同」，但 Q43 仍失败——「廉政合同」与「根据《…》」印在同一行，行内标题没有拆分，识别不到。

**结论**：在已经拍平的文本上做字段级切分不是正确解法。要修这四道题，需要更靠前的处理：
PDF 表格结构识别（`find_tables`）恢复单元格对应关系，以及按子合同（廉政合同 / 安全生产合同）分段。
两条都超出检索层范围，已回滚，基线保持 88%。

## 五、第二次否证：表格还原成字段文本（2026-11-16 实验）

上面的结论指向「更靠前的处理」，于是试了 PDF 表格还原：

- `pymupdf.find_tables` 确实能识别前附表（DOC003 p10–p13、DOC005 p7–p10、DOC009 p9–p10，
  均为「条款号 | 条款名称 | 内容」三列），也能完整取出目标行：
  「5.2.6 | 评标委员会的组成 | 评标委员会成员人数：5 人」、
  「3.5.1 | 投标保证金 | 不要求……本次招标不收取投标保证金」。
- 实现：`_page_text` 把落在表格 bbox 内的 block 丢弃，按行还原成
  「条款号 名称：内容」一行一个字段，插入原位置。

结果（两轮，第一轮还有 18% 丢文本的 bug，已修）：

| 指标 | 基线 | 表格还原（修 bug 后） |
|---|---|---|
| 条款数 | 766 | 774 |
| 总字数 | 265,416 | 268,356（+1.1%） |
| 页码区域命中 | 94.0% | **82.5%** |
| Q20 / Q24 是否可检索 | 否 | **否** |

失败原因：表格还原只改了文本顺序，**没有改切分粒度**——一行「5.2.6 评标委员会的组成：5 人」
仍然并进当前条款（`unit_level` 是「一、」级，`5.2.6` 是更细的层级，不会被切成独立条款），
所以答案行依旧淹没在 358–495 字的长条款里。要让它独立成条，必须把切分粒度降到字段级，
而那正是第一次否证过的做法（碎片互相竞争，掉到 82%）。

同时页码区域命中从 94.0% 掉到 82.5%：表格文本按 y 坐标重排后，一条跨表格边界的条款
起始文字不再落在声明页上。

**结论**：表格还原能提升可读性，但对检索指标是负收益，已回滚。
四道边界题在当前「条款为引用单元」的设计下无法修复——要么牺牲引用粒度换检索命中
（字段级切分，已否证），要么换一组更好的 PDF（前附表本身就是表格，不是叙事条款）。
这个取舍记在这里，不再重复尝试。

## 六、已修正

1. **Q01 出题锚点错误。** 原问法含「垃圾中转站」，该词只在合同首页条款出现，答案条款不含。已改问法，四组均命中第 1 名。
2. **切分盲区。** 只设上限不设下限、超长条款不切碎，导致 35% 条款超过 500 字、短条款永远检索不到。已规整（见第二节），并重写 30 题标注的 `relevant_clause_ids`（旧 id 全部通过文本匹配重映射，逐题人工核对）。

## 七、建议（按优先级）

| 项 | 建议 | 依据 |
|---|---|---|
| 默认权重 | 改为 `BM25_WEIGHT=1.0` / `DENSE_WEIGHT=1.0`（**已执行，2026-11-15**） | 三轮数据均优于 2:1，低于压制阈值 1.31 |
| Q20/Q24/Q34/Q43 | 记入已知边界；字段级切分与表格还原两条路均已否证（第四、五节） | 三次实验都不如基线，根因是「条款为引用单元」与「字段级定位」冲突 |
| rerank | 保持 `RERANK_ENABLED=false` | 四轮零召回增益，每题多 0.46 秒 |
| 种子集 | 扩到 50 题（**已完成，2026-11-15**） | 34 道可答题，1 题 ≈ 3 个百分点 |

## 八、复现

uv run python scripts/evaluate_retrieval.py            # A/B/C/D + 权重扫描
uv run python scripts/evaluate_retrieval.py --no-rerank # 只跑 A/B/C，不消耗重排配额
