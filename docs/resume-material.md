# 简历素材 · 合同条款智能问答系统

> 用途：简历条目、作品集描述、面试自述三层，全部基于实测数据。

## 一、简历项目条目（直接贴）

**合同条款智能问答系统（Contract-qa-RAG）** ｜ 个人项目 ｜ [github.com/ANSN1221/Contract-qa-RAG](https://github.com/ANSN1221/Contract-qa-RAG)

面向合同与招标文件的引用可核对问答系统。自研按条款切分的 PDF 解析管线，用 BM25 + 向量双路检索，生成后加引用校验与回退，并提供工具调用 Agent 路径。

- 技术栈：Python · LangGraph · Chroma · PyMuPDF · rank-bm25 · Streamlit · DeepSeek · bge-m3
- 实测：检索 Recall@5 88%、端到端双正确 93%（Agent）、拒答准确 96%（100 道人工核验种子题）

## 二、作品集 / 详细描述（贴作品集或面试前复习）

### 要解决的问题

合同与招标文件动辄几十页，人工查条款慢；直接问通用大模型，它会编造条款、给不出处。
现成 RAG 框架按字数切 PDF，条款被拦腰切断，召回后既读不完整，也无法回溯页码。

### 技术方案

| 环节 | 做法 | 取舍理由 |
|---|---|---|
| 解析切分 | 自研切分器，按「第X条」「一、」编号切，保留章节路径与页码 | 按字数切会把条款切断、页码不可回溯 |
| 检索 | BM25（关键词）+ 向量双路，RRF 加权融合（1:1） | 单一路径对同构表格、术语变体都会漏 |
| 生成 | 严格 JSON 输出，答案与引用 ID 强绑定 | 自由文本无法程序化校验引用 |
| 校验 | verify 节点：规则校验 + 模型核对，不通过回退重生成（≤2 轮） | 只生成不校验，编造与假引用拦不住 |
| Agent 路径 | 4 个工具：检索、读原文、读相邻条款、交卷 | 固定链路「一次召回定生死」，换说法重搜要靠模型自己判断 |

### 指标（100 道人工核验种子题，全部实测）

| 指标 | 数值 |
|---|---|
| 检索 Recall@5 | 88% |
| 端到端双正确（固定链路 / Agent） | 89% / 93% |
| 正确拒答（固定链路 / Agent） | 89% / 96% |
| 单题耗时（固定链路 / Agent） | 4.57s / 8.38s |

50 题与 100 题指标基本持平，说明不是小样本波动。

### 关键决策与负结果（能讲的部分）

1. **融合权重 1:1 而非 2:1**：实测 RRF k=60 时权重比超过约 1.31 会把单路命中挤出前 5。
2. **rerank 保持关闭**：四轮零召回增益，池外答案救不回来。
3. **三次尝试修表格类边界题全部失败并回滚**（字段级切分两次、PDF 表格还原一次）——
   根因是「条款是引用单元，字段是检索单元」的设计冲突，不是参数能调的。
4. **主备供应商自动切换**：只对「接口失败」切换，内容质量问题不换模型。

## 三、面试自述口径（STAR，约 90 秒）

**S（情境）**：做合同审查相关工具时，发现现成 RAG 框架把 PDF 按字数切，条款被切断，召回后无法回溯页码。

**T（任务）**：搭一个「引用可核对」的问答系统——每条回答都要能翻到原文的某页某条验证。

**A（行动）**：
- 没用现成切分器，自研按「第X条」「一、」切分，保留章节路径和页码
- 检索用 BM25 + 向量双路 RRF 融合，权重经三轮评测定在 1:1
- 生成后加 verify 节点做引用校验，不通过回退重生成
- 加了工具调用 Agent 路径，让模型自己决定检索几次、读哪条原文
- 100 题评测：Agent 双正确 93%、拒答 96%

**R（结果）**：端到端可用。更重要的是，三次想修表格类边界题都失败并回滚，最后定位到「条款是引用单元、字段是检索单元」的设计冲突——这个取舍比指标数字更能说明判断。

**一句话收尾**：这个项目我学到最多的是「什么时候不该继续调参」——三次负结果让我把问题从「怎么调得更好」重新定义为「引用单元和检索单元的冲突」。

## 四、可能被追问的问题（预演）

| 追问 | 答法 |
|---|---|
| 为什么不用现成切分器？ | 按字数切会把条款拦腰切断，页码不可回溯，有对照实验 |
| 为什么不只用向量检索？ | 单路对同构表格、术语变体漏召回；BM25 + 向量互补 |
| 为什么 rerank 关了？ | 四轮零召回增益，只能重排池内条款 |
| Agent 比固定链路强在哪？ | 能换说法反复搜、读原文，把「一次召回定生死」的风险摊薄 |
| 最大的坑是什么？ | 表格类边界题，三次尝试都失败，根因是引用单元 vs 检索单元冲突 |
| 怎么证明指标没注水？ | 100 题人工核验、判定关键词独立标注、评测脚本可复跑 |
